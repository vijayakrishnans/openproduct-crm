# openproduct.live listing (draft)

To publish through Orunbase the way `broke-crm` was. Nothing here is live
until the owner publishes it.

- **Name:** Orun Work
- **Slug:** `orun-work`
- **Tagline:** A desktop editor and agent for Orunbase.
- **Pitch:** Open any orun repository and see it as a graph: every
  component, every dependency, every environment. Run plans from a play
  button, inspect secrets by name, and hand the rest to an agent that
  works through orun's own MCP server and asks before it changes anything.
  Open source, for Windows.
- **Licence:** Apache-2.0
- **Language:** TypeScript (React), Rust (Tauri)
- **Source:** https://github.com/vijayakrishnans/openproduct-crm/tree/main/desktop/orun-work
- **Download:** the latest `orun-work-v*` release's `.exe` / `.msi`
- **Credits:** built on orun (MIT) and Orunbase; Tauri; Claude.
- **Screenshots:** the graph, the agent with an approval prompt, the inspector.
