# sdk

Runtime-agnostic TypeScript SDK for the OpenProduct CRM control plane API

A shared package of the openproduct-crm workspace, consumed by the components
below at build time.

## Depended on by

- **cli** — First-class TypeScript CLI for the OpenProduct CRM control plane API
- **web-console-next** — Next.js 15 + opennextjs/cloudflare delivery of the OpenProduct CRM web console (per-environment, Workers + Static Assets)
