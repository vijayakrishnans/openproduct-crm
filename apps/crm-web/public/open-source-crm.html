An open-source CRM, all the way down

The app, the API and everything that runs them are in one public repository, under one permissive licence.

Many products called open source keep the useful parts closed: the hosted version has features the code does not, or the licence forbids running it as a service. BrokeCRM has no closed part. What runs at brokecrm.cloud is what is in the repository, and the Apache 2.0 licence lets you use it, change it and host it, for yourself or for others.

What is in the code

  • The web app: contacts, companies, a drag-and-drop deal board, notes with attachments, tasks, tags, search, CSV import and export. It is built with React on top of Atomic CRM by Marmelab (MIT licence).
  • The API: every record belongs to an organization, and one organization can never read another's data.
  • Accounts for teams: sign-in by email code, Google or GitHub, organizations, invitations and roles.
  • The MCP server: thirteen typed tools that let an AI assistant work in the CRM.
  • Events and webhooks: changes are recorded and can notify your other tools.
  • The deployment: the configuration that deploys all of it, so a copy you run is the same product.

Hosted or self-hosted

Hosted: use BrokeCRM at brokecrm.cloud. It is free, and there is nothing to install.

Self-hosted: BrokeCRM runs on Cloudflare Workers with a Postgres database. The repository has the steps to deploy it to your own Cloudflare account. It is built and deployed with Orunbase.

Why open source matters for a CRM

A CRM holds the one list a business cannot afford to lose. With open code you can see exactly what happens to that list, take it with you, and keep the product running even if the people who host it stop. You can also change it: add a field, rename a stage, connect it to the tool you already use.

Questions people ask

What licence is BrokeCRM under?

The Apache License 2.0, for the whole product: the app, the API and the deployment. The interface it builds on, Atomic CRM, is under the MIT licence.

Can I self-host BrokeCRM?

Yes. It runs on Cloudflare Workers with a Postgres database, and the public repository has the steps to deploy your own copy.

Is the hosted version different from the code?

No. The hosted version at brokecrm.cloud is deployed from the same public repository.

Can I use it commercially?

Yes. The Apache 2.0 licence allows commercial use, changes and redistribution, as long as you keep the licence and attribution notices.
