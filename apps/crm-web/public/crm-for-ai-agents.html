A CRM your AI assistant can work in

BrokeCRM speaks the Model Context Protocol (MCP), so an assistant can do the CRM work you would rather not do by hand.

Most CRM data goes stale because entering it is a chore. BrokeCRM has an MCP server built in. Connect an assistant such as Claude and ask in plain language: "who do we know at Acme?", "log this call against Priya and remind me to follow up on Friday", "move the Northwind deal to won". The assistant reads and writes the same records you see in the app.

How to connect

  1. In your assistant, add a custom connector with the address https://mcp.brokecrm.cloud/mcp. It is the same address for everyone.
  2. Sign in with your BrokeCRM account when asked, and choose the organization the assistant should work in.
  3. Ask it something. It works as you, in that organization only.

A client that cannot sign in can send an organization API key as a Bearer token instead. A key with the viewer role can only read; a key with the builder role can also write.

What the assistant can do

  • Find things: search across contacts, companies, deals, tasks and notes, or list records with filters.
  • Summarize: get counts and open deals with totals per stage.
  • Add records: create contacts, companies and deals.
  • Keep them current: update a contact, a company or a deal, including moving a deal between stages.
  • Log activity: add a note, create a task, mark a task done.

What it cannot do

There are thirteen tools, each for one job, and no free-form database access. There is no tool that deletes records. An assistant cannot reach another organization's data, invite people or change settings. Access tokens last an hour and are refreshed while the connection is in use; removing a person from the organization ends their assistant's access at once.

Things people use it for

  • Pasting meeting notes and asking the assistant to log them against the right people and create the follow-ups.
  • Turning an email thread into a contact, a company and a deal.
  • A weekly review: which deals have gone quiet, which tasks are overdue.

BrokeCRM itself is free and open source, MCP server included.

Questions people ask

What is the BrokeCRM MCP server address?

https://mcp.brokecrm.cloud/mcp. It is the same for every account; the sign-in decides which organization the assistant works in.

Which AI assistants work with it?

Any client that supports the Model Context Protocol, including Claude. Clients sign in with OAuth, or send an organization API key.

Can the assistant delete my data?

No. There is no delete tool. An assistant can read, create and update records, and a read-only API key limits it to reading.

Does the MCP server cost extra?

No. It is part of BrokeCRM, which is free and open source.
