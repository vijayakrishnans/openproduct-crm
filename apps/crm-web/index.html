Fair questions

Is it really free?

Yes. There is nothing to buy and no card to enter. The free plan holds 10,000 contacts and 25 seats per organization, and an invitation counts as a seat until it is accepted. Those limits keep hosting costs sane.

What keeps it free?

We run it on Cloudflare, where a product this size is cheap to keep up, and donations cover the rest. If we ever stopped hosting, the code is yours to run.

How do I host it on my own Cloudflare?

You run the same product we run, on accounts you own. You need a Cloudflare account, a Supabase organization and a workspace on Orunbase, which does the deploying.

  1. Fork the repository. Everything is in one public repository: the app, the API, the database migrations and the infrastructure.
  2. Create a workspace on Orunbase and connect three things to it: your GitHub fork, your Cloudflare account and your Supabase organization.
  3. Point the fork at your workspace. Edit intent.yaml to name your workspace and your Cloudflare workers.dev subdomain.
  4. Merge to main. The pipeline creates the Postgres databases in your Supabase, deploys the workers to your Cloudflare, and brings up stage first, then production.

No Cloudflare or Supabase key is stored in the repository or in GitHub: each run gets a short-lived credential from your connections. Your copy answers on workers.dev from the first deploy, and you can add your own domain later. The runbook has every step.

Can an AI assistant use it?

Yes. BrokeCRM has an MCP server at https://mcp.brokecrm.cloud/mcp, so Claude and other assistants can read and update your CRM as you. See how to connect one.

Where does it come from?

The app is built on Atomic CRM by Marmelab, an open-source CRM under the MIT licence. BrokeCRM adds accounts for teams, hosting, an API and the MCP server, and is built and deployed with Orunbase. It is a separate product, not Atomic CRM and not a Marmelab product.
