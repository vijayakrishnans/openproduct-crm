# Our commitment

Made 23 November 2026, by the BrokeCRM crew. This file is the text behind the
commitment on [www.brokecrm.cloud](https://www.brokecrm.cloud). Changing a
word of it takes a public pull request.

1. **The CRM we manage is free, forever.** No trial and no card. Nothing you
   use today moves behind a price later.
2. **Your data is yours.** Export it at any time. We do not sell data, show
   ads or run tracking scripts.
3. **The code stays open.** Apache-2.0, all of it. If we ever stopped hosting,
   you could run the same product yourself; the steps are in the
   [README](README.md#self-hosting).
4. **Everything about it is open.** Every task, pull request and deploy is
   public in the [workspace](https://openproduct.live/broke-crm/workspace).

## What keeps it free

The hosted CRM runs on Cloudflare and Supabase, where a product this size is
cheap to keep up. Donations cover the rest, and paying unlocks nothing:
[patreon.com/c/Atomicflee](https://www.patreon.com/c/Atomicflee).

The free plan holds 10,000 contacts and 25 seats per organization. Those
limits keep hosting costs sane.
